# Single-Cell RNA-seq Analysis with Python

A practical implementation of a single-cell RNA sequencing (scRNA-seq) analysis workflow using Python, Scanpy and AnnData.

## Overview

This repository demonstrates core scRNA-seq analysis techniques using the public PBMC 3k dataset. It covers quality control, preprocessing, dimensionality reduction, cell clustering and marker gene analysis to explore cellular variation in gene expression data.

## Dataset

**PBMC 3k:** A public dataset of peripheral blood mononuclear cells used for exploring single-cell gene expression.

## Analysis Workflow

- Quality control and cell filtering
- Normalization and log transformation
- Highly variable gene selection
- Data scaling and principal component analysis (PCA)
- Nearest-neighbor graph construction
- Leiden clustering
- UMAP visualization
- Marker gene identification and cell-type annotation
